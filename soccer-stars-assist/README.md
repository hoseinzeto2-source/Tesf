# Soccer Stars Aim Assist

ابزار کمکی برای **Soccer Stars** که هنگام کشیدن مهره، خط شلیک را به‌صورت **خط‌کش بلند** و مسیر احتمالی **توپ** را روی صفحه نشان می‌دهد.

این نسخه برای **شبیه‌ساز اندروید روی PC** (BlueStacks، LDPlayer، ...) یا نمایش بازی روی مانیتور طراحی شده است.

## قابلیت‌ها

- تشخیص زمین بازی، توپ و مهره‌ها از روی تصویر صفحه
- تشخیص خط زرد هدف‌گیری بازی هنگام کشیدن مهره
- نمایش **خط‌کش سفید** برای ادامه خط شلیک
- نمایش **مسیر پیش‌بینی‌شده توپ** (آبی) و مسیر مهره (زرد)
- اگر شوت به گل برسد، مسیر توپ سبز می‌شود

## نصب

```bash
cd soccer-stars-assist
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## راه‌اندازی

### ۱) کالیبره کردن ناحیه بازی

بازی را باز کنید، سپس:

```bash
python src/calibrate_region.py
```

روی پنجره بازی یک مستطیل بکشید تا فقط همان ناحیه capture شود.

### ۲) اجرای ابزار

```bash
python src/main.py
```

یک overlay شفاف روی بازی ظاهر می‌شود. وقتی مهره را می‌گیرید و می‌کشید، خط‌کش و مسیر توپ نمایش داده می‌شود.

## تنظیمات

فایل `config/default.json`:

| کلید | توضیح |
|------|--------|
| `overlay.ruler_extension_px` | طول خط‌کش اضافه |
| `physics.max_shot_speed` | حداکثر سرعت شلیک در شبیه‌سازی |
| `goal.enabled` | فعال بودن تشخیص گل |

## محدودیت‌ها

- فیزیک **تقریبی** است و با بازی ۱۰۰٪ یکی نیست؛ برای کالیبره بهتر، مقادیر `physics` را تنظیم کنید.
- روی گوشی اندروید مستقیم کار نمی‌کند؛ نسخه بعدی می‌تواند Accessibility Overlay اندروید باشد.
- در بازی آنلاین ممکن است با قوانین Miniclip در تضاد باشد؛ این ابزار برای **دسترسی‌پذیری شخصی** طراحی شده است.
